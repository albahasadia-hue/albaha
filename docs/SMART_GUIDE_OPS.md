# دليل تشغيل وتحديث واختبار «المرشد الذكي» — موقع الباحة

يغطي هذا المستند آلية تحديث بيانات الدليل، إعدادات السيرفر وتكامل Gemini، وتقرير الاختبارات المنجزة مقابل معايير القبول في PRD «المرشد الذكي لموقع الباحة» على الفرع `feat/smart-guide-prd`.

---

## 1. طريقة تحديث دليل الباحة (Google Sheets → JSON)

- **مصدر التحرير**: جدول Google Sheets الرسمي الخاص بفريق المحتوى.
- **ملف التشغيل النشط**: `src/data/albaha_guide_144.json` (يبدأ بـ 144 سجلًا، الربط عبر المعرّف الرقمي `id`).
- **آخر نسخة صالحة (نسخة احتياطية تلقائية)**: `src/data/albaha_guide_144.last-valid.json` (تُحفظ تلقائيًا قبل تفعيل أي نسخة جديدة).

### خطوات التحديث الآمن

1. صدّر النسخة المحدّثة من Google Sheets بصيغة JSON مطابقة لهيكل `metadata` و`items` (مع الحفاظ على ثبات `id` للسجلات القائمة).
2. افحص الملف قبل التفعيل (فحص فقط دون تعديل الملف النشط):
   ```bash
   node scripts/import-guide-data.mjs --check path/to/new_albaha_guide.json
   ```
   أو لفحص الملف النشط الحالي:
   ```bash
   npm run guide:validate
   ```
3. عند نجاح الفحص، نفّذ الاستيراد الآمن:
   ```bash
   npm run guide:import -- path/to/new_albaha_guide.json
   ```
4. أعد البناء وتحقق من النتيجة:
   ```bash
   npm run build
   node scripts/test-smart-guide.mjs
   ```

### ما الذي يفحصه سكربت الاستيراد تلقائيًا؟

- سلامة بنية JSON ووجود مصفوفة `items` غير فارغة.
- الحقول الإلزامية لكل سجل: `id` (عدد صحيح موجب وفريد)، `name`، `governorate`، `category_key` المعتمد، `category_ar`.
- فحص الروابط (`http://` أو `https://` فقط، ورفض أي روابط معطوبة أو غير آمنة مثل `javascript:`).
- كشف التكرار الحرج في `id` (يرفض الاستيراد فورًا) والتنبيه على السجلات المحتمل تكرارها بالاسم/الهاتف (مثل `id=75`/`99`، و`id=101`/`102`، و`id=16`/`104` في النسخة الأولى) دون كسر التشغيل.
- **الاستمرار بآخر نسخة صالحة عند الفشل**: إذا فشل أي شرط جوهري، يتوقف الاستيراد دون لمس `src/data/albaha_guide_144.json` ويستمر الموقع بالعمل بآخر نسخة صالحة. كما يتحقق وقت التشغيل (`src/lib/guideCatalog144.ts`) من سلامة البيانات قبل تفعيل أي تحديث.

## 2. إعدادات السيرفر وتكامل Gemini API

- يتم استدعاء Gemini **من مسار السيرفر فقط** عبر `src/app/api/concierge/route.ts`، ولا يُكشف المفتاح أو اسم المزوّد أو إعدادات النموذج للزائر في الواجهة أو حالات الانتظار أو الأخطاء.
- متغيرات البيئة في السيرفر (انظر `.env.example`؛ ملف `.env.local` مستبعد من Git عبر `.gitignore`):
  - `GEMINI_API_KEY`: مفتاح Gemini API من Google AI Studio (يُضبط في بيئة السيرفر أو `.env.local` للتطوير).
  - `GEMINI_MODEL` (اختياري، الافتراضي `gemini-3.5-flash-lite` مع سلسلة تراجع تلقائية إلى `gemini-3.1-flash-lite` و`gemini-flash-lite-latest` عند عدم توفر النموذج أو الضغط).
- **الاسترجاع والعقد المنظّم**:
  - يسترجع `src/lib/smartGuideEngine.ts` السجلات المرتبطة بالسؤال فقط (بحد أقصى 6 سجلات مختصرة) وسياق المحادثة اللازم، ويُمرّرها للنموذج مع `responseSchema` بصيغة JSON (`replyText`, `placeIds`, `placeReasons`).
  - يتحقق `src/lib/smartGuideContract.ts` من كل `placeIds` والإجراءات ضد القائمة المعتمدة؛ ويستخرج الصور والأرقام وروابط الحجز والواتساب والموقع الرسمي من السجل الموثّق في الكتالوج فقط.
  - عند غياب المفتاح أو تعذّر الاتصال أو انتهاء الحصة، يُعرض الرد المحلي الموثّق متى توفر مع الحفاظ على السؤال وإظهار إجراء «إعادة المحاولة»، وبدون ظهور كلمة `Gemini` في أي نص موجه للزائر.

### ج) الفحص المرئي والتفاعلي في المتصفح (`http://127.0.0.1:3010/`)

- **الكمبيوتر `1280×800` (100%)**:
  - اللوحة تفتح من اليمين باتجاه RTL وبكامل الارتفاع، مع إزاحة نظيفة للموقع والهيدر بجانبها دون تغطية المحتوى (`overflowCount = 0`، لا يوجد شريط تمرير أفقي).
  - هيدر كحلي رفيع (`#061A33`) بالأيقونة والعنوان يمين والإغلاق يسار، خلفية كريمية (`#FAF7F0`)، وأخضر سعودي (`#006C35`) للروابط والإرسال.
  - رسالة الترحيب «وش ودّك تكتشف اليوم؟» مع 4 اختصارات بداية تختفي فور إرسال أول رسالة.
  - صفوف الوجهات مدمجة: صورة مصغرة يمين، اسم الوجهة بالأخضر بدون خط تحته + سهم مائل `↖` يسار الاسم داخل رابط واحد، وإجراءات خفيفة («على الخريطة»، «أضف لرحلتي»، «اتصال»، «حجز»، «الموقع الرسمي»، و«واتساب» فقط عند توثيقها بالمصدر).
  - الضغط على رابط وجهة أو إرسال «ودّني للخريطة» / «افتح قرية ذي عين» ينقل داخل الموقع مع الحفاظ على المحادثة مفتوحة ومتصلة.
  - مفتاح `Escape` يغلق اللوحة ويعيد التركيز بلوحة المفاتيح إلى `#sirajLauncher`.
  - عدم ظهور كلمة `Gemini` في أي موضع بالواجهة.
- **الكمبيوتر عند تكبير 125% (`1024×640`)**:
  - تخطيط جنبي سليم (`#header` و`#tourGuideView .container` يسار اللوحة، `#agentPanel` يمينًا بعرض `312.8px`)، خانة الكتابة وزر الإرسال ظاهرين وثابتين، و0 تجاوز أفقي (`overflowCount = 0`).
- **الكمبيوتر عند تكبير 150% (`853×533`)**:
  - الموقع ظاهر بجانب اللوحة (`#agentPanel` بعرض `304px`، `#main` بعرض `534px` بعمود واحد مريح)، والهيدر وخانة الكتابة ثابتة دون قص أو تجاوز أفقي.
- **الموبايل عند عرض `360px` (`360×800`)**:
  - اللوحة تتكيف مع كامل عرض الموبايل، مع دعم `visualViewport` لارتفاع لوحة المفاتيح (`--sg-vvh`, `--sg-vvt`) وخط إدخال `16px`، دون أي تجاوز أفقي، وخانة الكتابة وزر الإرسال واضحان وقابلان للنقر.
